# Ai-llowance 0.6.6 · Dashboard and account connections

See when a five-hour limit is exhausted or a reading is stale directly beneath the weekly allowance. Accounts with matching names are distinguished by provider and, when needed, email. Chart style and comparison controls now sit in the chart header.

The dashboard pauses chart rendering while fully covered and continues updating readings. Chart hover reuses prepared samples, the activity heatmap does less work per refresh, and Claude reset times are parsed more efficiently.

Connecting an account refreshes just that account. Claude sign-in prompts stay visible when another account refreshes, and shared Codex recovery now points to Codex. The glass dashboard also has a native Mac title bar.

For Apple silicon and Intel Macs running macOS 14 or later. Choose Settings → Updates → Check for Updates, then Install and Relaunch.

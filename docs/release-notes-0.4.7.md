# Ai-llowance 0.4.7 · build 230

Your dashboard, your view.

- New default Overview combines individual account trends, a seven-day usage-share donut, stacked daily bars, and the activity heatmap.
- Choose Glow, Line, Area, Bars, Dots, Ring, Pie, or Gauge. Your dashboard style is saved between launches.
- Richer gradients and smoother trends, with a labeled fitted percentage scale and a saved option for the full 0–100% scale. Hover for exact readings; gaps and quota resets stay separate.
- Customize the dropdown: account emails, reset times, progress bars, provider headings, comfortable spacing, and individual quota limits. The live preview follows your choices.
- Poor connections no longer blank verified menu-bar readings: last-known values remain visible with a ~ marker until refresh succeeds. Account identity and reconnect safeguards remain in place.
- Cleaner five-hour quota badges and improved menu-bar icon alignment.

Usage-share and daily bars compare observed subscription allowance consumption in percentage points, not tokens, cost, or coding hours. Different plans have different capacities. API accounts are excluded from those comparisons. Ring, pie, and gauge styles show current remaining versus used allowance; API accounts retain history charts.

Existing account connections, settings, and usage history are retained. No account reconnection is required by this update.

Release artwork is an illustration, not an app screenshot.

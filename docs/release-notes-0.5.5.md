# Ai-llowance 0.5.5 — Grok Bot, in your menu bar

- Connect Grok & Grok Bot using your existing official Grok CLI sign-in.
- See the unified shared allowance for Grok, Grok Bot, and Cursor, including its reset time, history, and menu-bar reading.
- Keep subscription usage separate from xAI API credits. Missing data and unsupported legacy plans stay unavailable.
- Account and workspace checks prevent a different CLI sign-in from silently replacing your connected account.

Requires the official Grok CLI and a unified subscription. Run `grok login` with the same account as Grok Bot, then connect Grok & Grok Bot in Accounts. Whole percentages can differ slightly from Grok Bot's rounded display.

Developer ID signed and notarized for Apple silicon and Intel Macs. Use Check for Updates in Ai-llowance to install. Promotional artwork is an illustration, not a screenshot.

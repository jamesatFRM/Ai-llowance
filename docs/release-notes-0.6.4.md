# Ai-llowance 0.6.4 — More insight. Your way.

Build a dashboard that works for you with six optional analytics views:

- **Weekly pace:** follow your weekly allowance, with an estimated balance at reset when enough fresh history is available.
- **Unused allowance:** see the last observed balance before previous weekly resets.
- **Limit pressure:** compare weekly and 5-hour limits without mixing their percentages.
- **Burn rate:** find recent consumption spikes in allowance points or API dollars.
- **Usage calendar:** see daily patterns, measured active days and observed streaks.
- **Credit runway:** estimate how long API credits may last from measured spending.

Open **Usage → Customize dashboard** to add views. Each card remembers its account, compatible chart style, period, width and collapse state. Reorder with card menus or the layout editor, hide and restore cards, or return to the default layout without changing connections, account names, colors or individual chart choices. Existing dashboards stay as they are until you add a view.

All analytics use history already saved on this Mac. There are no extra provider refreshes or external analytics services. Sparse history gets an explanation, missing readings stay distinct from zero usage, and forecasts pause while readings are stale. API credit top-ups and quota resets are excluded from measured consumption. Reset observations report how far they were recorded before the reset.

This universal macOS release is Developer ID signed and notarized by Apple. Install through **Check for Updates**. Connected accounts, settings and saved usage history are preserved.

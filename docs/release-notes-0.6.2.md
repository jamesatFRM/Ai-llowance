# Ai-llowance 0.6.2 — Weekly limits, clearly labeled.

Build 247 clarifies Claude weekly limits and fixes missed clicks on dashboard collapse controls.

- **Clear weekly limit names.** The dropdown now distinguishes **Weekly · All models** from separate named limits such as **Weekly · Fable**. Each row retains its own reported percentage and reset time.
- **Consistent main reading.** The account's primary weekly percentage continues to use its all-model allowance. The corrected labels explain why a separate weekly limit can have a different remaining percentage.
- **Saved readings clarified.** The shared formatter also corrects already-saved readings and the dropdown preview. An existing connection can show the corrected labels without reconnecting.
- **Reliable collapse controls.** Account cards, allowance use and allowance activity now use consistent, larger buttons. The whole button area accepts a click, including the space around the chevron, as cards collapse and rearrange.

Existing account settings, usage history, provider reports and menu-bar label preferences are preserved. This fix adds no background polling or timers.

Signed and notarized for Apple silicon and Intel Macs on macOS 14 or later. Open Settings → Updates → Check for Updates, then Install and Relaunch.

The release artwork uses illustrative UI, not an actual app screenshot. Named limit labels are preserved as supplied by Claude Code; this release does not map provider labels to other model names.

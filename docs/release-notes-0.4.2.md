# Ai-llowance 0.4.2 (build 224)

Clearer settings, accounts, and allowance readings.

- **One-page settings:** all preferences together, with a live menu-bar preview and visible display choices.
- **Clearer quota labels:** the dropdown detail option explains which subscription windows it shows, with an example.
- **Multiple accounts:** connected emails appear under each provider, with an explicit Add another account action where supported.
- **Connection flow fixes:** setup stays on its own page while connecting, and a previously connected account cannot be mistaken for a newly verified connection.
- **Responsive charts:** one to four visible account tiles share the available width and animate when the selection changes. Reduce Motion is respected.
- **Honest grouped readings:** combined percentages say “avg” or “lowest”, so an average cannot be mistaken for one account’s allowance. New installations show accounts separately; existing display choices are preserved.

Automatic, Light, and Dark appearance were checked in the running preview. Accounts and settings are preserved across updates.

Release artwork is an illustration, not an application screenshot.

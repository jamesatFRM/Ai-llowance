# Ai-llowance 0.4.0 — Your usage dashboard

- A new dashboard brings Overview, History, Accounts, and Settings together while keeping the menu-bar popover compact.
- Local usage history shows observed allowance, credit balances, and spending with account and time-range filters. It uses existing refreshes and retains up to 96 recent readings per account, for up to seven days. Gaps are not estimated; allowance snapshots are not token counts.
- Overview suggests a verified available Claude or Codex account within each provider. Use this account opens a new CLI session with that profile; it does not move an existing chat or switch the desktop app.
- Optional detailed quota labels show the individual quota windows in the popover. Compact labels remain the default.
- Simple account setup shows assistant discovery, sign-in, and first-reading verification. Advanced connections remain available under Settings.

Release artwork is an illustration, not an application screenshot.

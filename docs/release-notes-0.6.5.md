# Ai-llowance 0.6.5 — The right face for Grok Bot

Grok shared-subscription accounts now use the official Grok Bot face mark instead of a generic star. The icon is consistent in the menu bar, dropdown, dashboard, Accounts and Settings previews, with centered menu-bar sizing and native light/dark rendering.

The small icon is bundled and cached locally. No extra downloads, dependencies, provider reads or background work. Account connections, settings and usage history are preserved.

Signed and notarized for Apple silicon and Intel Macs on macOS 14 or later. Open Settings → Updates → Check for Updates, then Install and Relaunch.

Release artwork is illustrative UI, not an app screenshot.

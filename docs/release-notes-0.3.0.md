Ai-llowance 0.3.0 makes setup and daily allowance checks simpler:

- Guided connections using installed CLI sign-ins, automatic tool rediscovery, and account-specific recovery.
- Compact expandable account rows, limiting allowance and reset countdowns, recent local history, and optional quiet alerts.
- Claude identity protection matching Codex, including duplicate-account rejection.
- Cached startup display and adaptive background checks; organization spending checks hourly.
- Copilot quota support (preview), OpenRouter key budgets, Vercel AI Gateway team credits, and xAI API prepaid credits.
- Optional launch at login and per-account Chrome profile choices.

Drag Ai-llowance into Applications, or use Check for Updates in the installed app. Existing accounts and preferences migrate automatically.

Universal macOS 14+ preview. This automated build is ad-hoc signed and unnotarized; it is not an Apple-notarized production release. Copilot requires its CLI. New providers require their own sign-in or API key; Cursor and Gemini currently open their usage pages rather than displaying unverified quota readings.
